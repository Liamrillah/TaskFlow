
## Run Locally

#### 1. Set Up Tech (Fastest way)
   * Install XAMPP
   * Run it, start Apache and MySql

#### 2. Clone the project

```bash
  git clone https://github.com/Liamrillah/TaskFlow
```

Move (or clone directly)  into XAMPP's standard `htdocs` directory:

Windows: `C:/xampp/htdocs/todolist-app`

macOS: `/Applications/XAMPP/xamppfiles/htdocs/todolist-app`

Linux: `/opt/lampp/htdocs/todolist-app`

Note, if you install xampp in other directory search xampp and just follow the directory


#### 3. Set up Database

After Running xampp, click Admin in MySql to go to LocalAdmin.
Click sql tab and copy paste file in db/TaskFlow.sql and click go

or

Click import tab and just import db/TaskFlow.sql in there

#### 4. Run the App

just open this link
```bash
http://localhost/todoApp/php/register.php
```
